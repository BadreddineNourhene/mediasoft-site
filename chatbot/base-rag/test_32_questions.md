## 2. [fonctionnelle] Comment transformer un devis en facture dans Sage 100 Gestion commerciale ?

*HTTP 200, 1.9 s, répondu ; sources : https://sage100cloud.online-help.sage.fr/comment-transformer-un-document-des-ventes/, https://sage100cloud.online-help.sage.fr/imprimer-un-document-des-ventes/, https://www.sage.com/fr-ma/produits/sage-100/gestion-commerciale/*

Pour transformer un devis en facture dans Sage 100 Gestion Commerciale, suivez ces étapes :

1. Ouvrez le menu **Traitement > Documents des ventes**.
2. Sélectionnez le devis à transformer (la sélection multiple est possible uniquement pour un même client avec un en-tête identique).

5. Saisissez le numéro de la première pièce à générer et la date.
6. Validez l'opération.

Cette fonctionnalité permet de générer la facture sans ressaisie des données. Attention, le document initial (le devis) est détruit et ne sera plus consultable après la transformation ; il est conseillé de le sauvegarder au préalable.

## 3. [fonctionnelle] Comment faire le lettrage des comptes clients dans Sage 100 Comptabilité ?

*HTTP 200, 1.7 s, répondu ; sources : https://sage100cloud.online-help.sage.fr/lettrer-automatiquement-les-ecritures/, https://www.sage.com/fr-ma/produits/sage-100/comptabilite/, https://sage100cloud.online-help.sage.fr/editer-les-rappels-et-releves/*

Pour lettrer les comptes clients dans Sage 100 Comptabilité :

1. **Activer le lettrage** : dans l’onglet Paramètres > Options de traitement de chaque compte client, cochez « Autoriser le lettrage automatique ».  
2. **Lancer le traitement** : allez dans Traitement > Gestion des comptes généraux (ou Gestion des comptes tiers).  
3. **Choisir le mode** : cliquez sur Automatique dans la barre de fonctions, vérifiez que l’option Lettrage est cochée, sélectionnez le mode (monnaie courante ou devise) et le type (montant ou numéro de facture).  
4. **Paramétrer les critères** : définissez la puissance de lettrage, les fourchettes de comptes et de dates, et les éventuels ajustements d’écart.  
5. **Valider** : cliquez sur Valider pour lancer le lettrage.  

Le lettrage doit être effectué avant d’envoyer les relances clients.

## 8. [fonctionnelle] Comment faire le rapprochement bancaire dans Sage ?

*HTTP 200, 10.6 s, répondu ; sources : https://sage100cloud.online-help.sage.fr/effectuer-un-rapprochement-bancaire-manuel/, https://sage100cloud.online-help.sage.fr/mettre-en-place-le-rapprochement-bancaire-automatique/, https://www.sage.com/fr-ma/produits/sage-100/moyens-de-paiement/*

Le rapprochement bancaire manuel dans Sage 100 Comptabilité consiste à pointer les écritures du journal de banque avec le relevé en suivant les étapes suivantes.  
Vérifier que le mode de rapprochement (Trésorerie ou Contrepartie) est défini sur le journal, ouvrir Traitement > Rapprochement bancaire manuel, sélectionner le journal et la date de l’extrait, puis saisir la référence dans la zone Pièce de trésorerie.  
Pointer les écritures une par une (colonne P) ou en sélection multiple, puis ajouter et pointer les écritures manquantes comme les frais bancaires.  
Une fois toutes les lignes pointées, valider et fermer la fenêtre pour finaliser le rapprochement.  
Cette opération assure la concordance du solde bancaire avec la comptabilité, évite les écarts et facilite le suivi des flux financiers.
