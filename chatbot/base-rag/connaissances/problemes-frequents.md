# Problèmes fréquents et premières vérifications

Premiers gestes à essayer soi-même avant d'appeler le support Mediasoft. Si le problème continue après ces vérifications, contacter le support : help desk https://helpdesk-ms.com/, +216 31 435 825 (Tunis), +216 73 822 546 (Sousse) ou WhatsApp +216 52 444 444, en précisant le logiciel et le message d'erreur exact (capture d'écran).

## Vérifications de base, quel que soit le logiciel

- Vérifier la connexion internet ou réseau (ouvrir un site web, vérifier que les autres postes fonctionnent).
- Fermer complètement le logiciel puis le rouvrir ; si le problème continue, redémarrer l'ordinateur.
- Noter le message d'erreur exact ou faire une capture d'écran : le support en aura besoin.
- Vérifier si le problème touche un seul poste ou tous les utilisateurs : s'il touche tout le monde, le serveur ou le réseau est probablement en cause et il faut contacter le support.
- Ne jamais supprimer ni déplacer les fichiers de la base de données ou du dossier société pour « réparer » : appeler le support.

## Sage : le logiciel ne s'ouvre pas ou le dossier société est inaccessible

Si Sage 100 ou Sage 50c ne s'ouvre pas, ou affiche que le fichier ou la base de la société est introuvable ou inaccessible :
- vérifier que le poste est bien connecté au réseau de l'entreprise et que le serveur où se trouvent les dossiers Sage est allumé ;
- vérifier que les autres utilisateurs arrivent à ouvrir le dossier : si personne n'y arrive, le problème vient du serveur ;
- fermer Sage sur le poste, redémarrer l'ordinateur et réessayer.
Si le dossier reste inaccessible, ne pas le restaurer ni le recréer soi-même : contacter le support Mediasoft, qui intervient à distance.

## Sage : message de licence expirée, de licence invalide ou de mode démonstration

Si Sage affiche une licence expirée, un nombre d'utilisateurs dépassé, une clé invalide ou passe en mode démonstration, la licence ou l'abonnement doit être renouvelé, mis à jour ou réactivé. Contacter Mediasoft (revendeur Sage en Tunisie) au +216 31 435 825 ou au +216 73 822 546, ou via le help desk, avec une capture du message : Mediasoft vérifie le contrat et réactive la licence.

## Sage : le logiciel est lent

Si Sage 100 est lent : vérifier la connexion réseau ou internet du poste, fermer les autres programmes lourds, vérifier si la lenteur touche tous les utilisateurs ou un seul poste. Une lenteur générale peut venir du serveur, de la base de données ou d'un dossier à réorganiser : le support Mediasoft peut analyser et optimiser l'installation.

## Sage : sauvegarde des données et clôture d'exercice

Il est essentiel de sauvegarder régulièrement les dossiers comptables et commerciaux, et de faire une sauvegarde avant toute opération importante (clôture d'exercice, mise à jour, changement de version). Pour mettre en place des sauvegardes automatiques, restaurer une sauvegarde, clôturer un exercice ou ouvrir un nouvel exercice, Mediasoft peut accompagner le client à distance pour éviter toute perte de données.

## Sage : mise à jour ou changement de version

Pour passer à une nouvelle version de Sage (par exemple de Sage 50c vers Sage 100, ou vers la dernière version de Sage 100), ou pour ajouter un module (Paie et RH, Gestion commerciale…) ou des utilisateurs, contacter Mediasoft : un consultant vérifie la compatibilité, sauvegarde et migre les données, puis forme les utilisateurs.

## Divalto Infinity : problème de connexion ou erreur

Si Divalto Infinity n'arrive pas à se connecter ou affiche une erreur :
- vérifier la connexion internet ou réseau du poste ;
- vérifier le nom d'utilisateur et le mot de passe (attention aux majuscules) ;
- vérifier si les collègues arrivent à se connecter : si personne n'y arrive, le serveur est en cause ;
- fermer Divalto et le relancer.
Si l'erreur continue, contacter le support Mediasoft avec une capture d'écran du message d'erreur et le nom du module concerné (gestion commerciale, comptabilité, production, entrepôt/WMS…).

## Bitrix24 : mot de passe oublié ou impossible de se connecter

Sur la page de connexion de Bitrix24, cliquer sur « Mot de passe oublié ? » et saisir son adresse e-mail : un lien de réinitialisation est envoyé (vérifier aussi le dossier spam). Vérifier que l'adresse du portail Bitrix24 de l'entreprise est la bonne. Si le compte est bloqué ou n'existe pas, l'administrateur du portail Bitrix24 de l'entreprise peut réinviter l'utilisateur ; Mediasoft peut aussi aider l'administrateur.

## Bitrix24 : ajouter un utilisateur, l'application mobile, les notifications

Pour ajouter un collaborateur, l'administrateur du portail l'invite par e-mail depuis la liste des employés. Bitrix24 existe en application mobile (Android et iPhone) et en application de bureau (Windows et Mac) : se connecter avec la même adresse de portail et les mêmes identifiants. Si les notifications n'arrivent pas sur le téléphone, vérifier que les notifications de l'application Bitrix24 sont autorisées dans les réglages du téléphone. Pour configurer le CRM, les tâches, l'automatisation ou le centre de contact, Mediasoft (partenaire Bitrix24) accompagne le client.

## Microsoft 365 : mot de passe oublié ou compte bloqué

Pour un mot de passe Microsoft 365 oublié, utiliser le lien « Mot de passe oublié » sur la page de connexion Microsoft, si la réinitialisation en libre-service est activée dans l'entreprise. Sinon, l'administrateur Microsoft 365 de l'entreprise peut réinitialiser le mot de passe depuis le centre d'administration. Mediasoft, partenaire Microsoft, peut aussi intervenir si l'entreprise lui a confié la gestion de ses comptes.

## Microsoft 365 : Outlook ne reçoit plus les e-mails ou ne se synchronise pas

Si Outlook ne reçoit plus d'e-mails : vérifier la connexion internet, vérifier en bas de la fenêtre qu'Outlook n'est pas « Déconnecté » ou en mode hors connexion (onglet Envoi/Réception, bouton « Travailler hors connexion »), fermer puis rouvrir Outlook, et vérifier si les e-mails arrivent sur Outlook sur le web (https://outlook.office.com). Si la boîte est pleine, supprimer ou archiver d'anciens e-mails. Si le problème continue, contacter le support Mediasoft.

## Microsoft 365 : Teams, OneDrive et licences

Si Teams ne se connecte pas ou ne se met pas à jour : quitter complètement Teams (clic droit sur l'icône près de l'horloge puis « Quitter »), le rouvrir, ou utiliser Teams sur le web (https://teams.microsoft.com). Si OneDrive ne synchronise plus : vérifier que l'icône OneDrive près de l'horloge n'affiche pas d'erreur et que l'espace de stockage n'est pas plein. Si Word, Excel ou Outlook indiquent « Produit sans licence » ou « Activation requise », la licence Microsoft 365 de l'utilisateur doit être attribuée ou renouvelée : contacter Mediasoft.

## Power BI : le rapport ne s'actualise pas

Si un rapport Power BI affiche d'anciens chiffres ou que l'actualisation échoue : vérifier dans le service Power BI la date de la dernière actualisation et le message d'erreur dans l'historique d'actualisation. Les causes fréquentes sont un mot de passe de la source de données qui a changé, une passerelle (gateway) arrêtée sur le serveur, ou une source de données déplacée ou renommée. Mediasoft, qui conçoit les tableaux de bord Power BI, peut corriger la connexion et l'actualisation planifiée.
